# Foodie

Foodie is a complete React food ordering website built with React Router, Context API, CSS, and localStorage.

## Features

- Home, menu, cart, checkout, and order success pages
- Search and category filtering for static food data
- Add, increase, decrease, and remove cart items
- Cart persistence with localStorage
- Checkout validation and fake order confirmation
- Responsive CSS for mobile, tablet, and desktop

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.
